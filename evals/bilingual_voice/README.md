# 第一轮双语语音诊断集

2026-11-04，新建 24 条问题和 2 条无语音控制；两轮。初次运行前冻结输入和产品代码，随后发现中英混说漏词、个别中文词义问法绕过词表、漏例句等问题。本集已转为开发诊断用途，不能再作为最终独立验收集。

candidate-offline(-transcribed).json 和 candidate-live(-transcribed).json 保留第一版真实失败。baseline 文件的冻结模块数据路径不正确，部分词义请求发生 FileNotFoundError，属于评测脚本错误；这些 baseline 结果全部排除，不计算修改前后的质量差或延迟差。第二批 release 集修正了脚本的数据路径，再重新运行完整对照，没有把脚本异常当成产品失败。

第一轮录音使用 macOS Flo 普通话与 Daniel/Flo 英语拼接；输入有独立哈希，较多短英语词被省略或听成别词，“买/卖”也发生混淆。这些失败不会通过按参考文本改写转写来消除。诊断中的原始输入、响应 WAV 位于 .local/bilingual-voice/。第二批的合成中文音色更换为 Tingting，使用全新问题；两批的混说结果应分别看待。
