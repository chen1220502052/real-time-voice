# 单元词汇文字聊天部署与语音可行性实测

更新时间：2026-10-23（北京时间）。线上版本：`rtv-20261023-curriculum-chat-r1`。

文字入口：https://aimaoren.com/text.html 。登录后选择教材、年级、册次和学习单元。

## 已部署内容

文字 HTTP 接口默认使用 Deep Agents 0.5.9 + langchain-deepseek 1.1.1，沿用服务器现有 DeepSeek Flash 配置及密钥。模型配置兼容 CHAT、LLM 和旧 OLLAMA 环境变量，关闭思考模式。

词汇范围累计同教材、同版次从四年级到当前单元的参考词汇。五上 Unit 10 包含四年级上下册和五上前十个单元，共 34 个单元来源。每条回复最多 1 种表外词，出现次数 / 英文 token 数不超过 3%；短回复通常须零表外词。学生提到的词和专有名词也检查。

真实模型测试促成的修正：改写指令明确禁止已检测出的表外词，多轮修订累计禁止词，并要求简短表达；明确请求中文帮助时允许纯中文解释，但混入的英文仍检查；补充 told/tell、spoke/speak、said/say 等常用不规则变化的判定，只有已知原形才接受。

现有词表包含原创主题补充词，部分前序册次仍缺失。例如一些日常词在参考列表中没有，模型只能换用代词或更简单的说法。零表外词并不证明教材词表完整，也不证明回答的信息量充足。页面显示资料覆盖提示，可导入核对词表。

部署合并并保留了同期远端的课程册次标签、页面导航和控件布局更新。使用独立运行环境 `/opt/real-time-voice/.venv-curriculum-20261023`，通过 systemd 的 `curriculum-runtime.conf` 指向该解释器。原运行环境保留。程序和运行配置备份位于 `/var/backups/real-time-voice/rtv-20261023-curriculum-chat-r1`；激活脚本在健康检查或公网基础验收失败时恢复原程序、配置和解释器。账户数据库及原语音配置沿用现有设置。

## 验证

- 本地相关后端回归 60 项通过；远端候选环境回归 48 项通过。
- 两个词汇范围、共 8 条真实模型对话通过最终词汇检查，覆盖普通聊天、上下文追问、陌生话题及中文解释。最终输出均没有表外英文 token。
- 切换后的公网基础验收 161 项通过，包含账户隔离、118 个教材单元、1,030 条录音、文本开场、幂等重放和语音 WebSocket 握手。
- 公网真实文字生成另验收开场和三条模型回复，全部通过，表外英文 token 为零；三条模型回复耗时分别为 5.80、1.27、2.05 秒。测试使用临时账户，退出后清理该账户，详见 `public-chat-report.json`。

## 语音可行性

在远端隔离的 loopback 服务中，把固定六年级上册 Unit 1 注入 CurriculumChatBot，再接入现有真实阿里云 NLS ASR 和 Piper TTS。与 EnglishChatBot 基线使用同一组 16 kHz WAV，关闭预取；模型与 ASR/TTS 均为真实调用。模型预热完成后才送入 WAV。

最后一轮结果如下。计时起点是服务端 ASR 定稿，终点是 TTS 首段 PCM 就绪；不包含用户说话、VAD 断句、浏览器播放和扬声器延迟。

| 样本 | 原语音 Bot | 单元词汇 Bot |
| --- | ---: | ---: |
| Hello, how are you today? | 1.03 秒 | 5.25 秒 |
| Tell me a fun fact about cats. | 1.00 秒 | 3.33 秒 |

两组均完成开场和两条回复，收到真实音频，无流水线错误。单元词汇版所有最终英文通过词汇审计。它可用 They 指代学生刚提到的 cats，因此受限版本使用词汇审计和上下文审阅，未套用旧测试中“回答必须出现 cat 字面词”的断言；原测试默认内容断言保留。

另完成真实 WAV 的两次打断检查：识别到后续输入，旧回复被取消，`lateOldAudio=0`，没有错误。播放回执为模拟的 0 ms / 550 ms，不能代替手机真实麦克风和扬声器验收。最初未预热的实验因 VAD 首次加载发生队列溢出，已作废，以上结果来自启用预热后的复测。

结论：协议、ASR、TTS 和打断链路可复用，但当前“整条生成 → 词汇检查 → 必要时改写”的方式会明显增加实时语音等待。此次只切换线上文字生成；线上语音仍使用原 EnglishChatBot。语音客户端目前只传年级，教材单元是本次隔离实验注入的，尚未接入公开语音选课流程。

下一步优先补齐核对词表、将 chapterId 贯穿语音会话，再评估逐句检查后送入 TTS，并比较首段 PCM 延迟及失败率。这是小样本可行性实验，不应据此估算 P95 或发布语音体验承诺。

不含凭据的测试证据保存在本地忽略目录 `.local/curriculum-release-20261023/`，包括 direct-report、voice-report、public-chat-report 及验收清单。
