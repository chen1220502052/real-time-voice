# 批量词句库与多轮检索验收

日期：2026-10-24。发布版本：`rtv-20261024-bulk-dialogue-r1`。

## 已入库的内容

回复库从 44 条扩充至 591 条：101 条教材来源回复，490 条原创预置回复。新增部分为 99 条带明确教材引用提示的回复、448 条原创常见对话；99 条教材回复复用 90 条原句记录，并包含 9 组经出处验证的教材问答，不能把这些数字相加理解为新增教材原文数量。

另外建立 `textbook_sentences`，保存 90 条“单元／页／句子”记录，去重后为 85 个不同句子；每条保留章节 ID、原图 SHA-256 和来源路径。现有已核验转写覆盖四年级上册 12 个单元。其他章节 ID 的缺口列在 [逐单元覆盖清单](data/chat-library-coverage-20261024.json)，没有把原创模板标为教材原文。

原创素材覆盖饮食、动物、运动、学科、天气、活动及基础社交。使用固定语法模板和受控词槽离线展开，再自动校验；不调用实时模型批量生产，也不读取任何学生会话作为公共素材。数据的 `reviewMethod` 明确记录为模板与词汇校验，不表示每条经过人工审定。

按本次验收的 163 个累计词汇快照编译后，生成 37,275 条“单元—可用回复”映射、7,804 条“单元—已学教材原句”映射。它们是按单元重复使用同一素材的映射数，不是独立回复数。每个单元可用回复数量和缺口可在覆盖清单中检查。

## 多轮匹配与范围

回复、词槽先决词和教材来源均在离线入库时检查。不能使用未来单元的教材来源；所有可检索英语回复都要求属于当前累计词汇范围。模型兜底仍沿用此前不设硬词汇白名单的规则。

Yes／No、单词回答、Why 等必须匹配上一轮实际交付的完整问题或陈述。例如：

```text
孩子：I like apples.
机器人：Do you like bananas?
孩子：Yes.
机器人：What do you like to eat?
孩子：Bananas.
机器人：Do you like apples?
孩子：No.
机器人：What do you like?
孩子：Let us talk about sports.
机器人：What sports do you like?
孩子：Football.
机器人：Do you like basketball?
```

上述六轮在公网全部命中预置库。否定句保留否定含义；复合提问、未知话题、个人信息回忆和没有可靠上下文的短句继续走模型。新查询会排除近期已交付的完整回复，在有可用替代时轮换答案。

`Read a sentence from this unit.`／`读一句本单元课文` 只引用当前单元，连续请求可以轮换尚未使用的原句。`In the book, ...`／`课文里，...` 可查询已收录的明确教材问答。缺少可用原句时直接如实提示，不让模型编造教材原文；这类提示不计为检索命中。

新数据使用原有可重建教材库，生成结果和个人会话仍在独立 `CHAT_DIALOGUE_DB`。发布没有覆盖私有对话数据。依赖学生个人事实的回答没有加入本次批量公共库。

## 命中率与速度

固定场景集为 `tests/fixtures/chat/retrieval-evaluation.json`：40 个单独维护的合成场景，包含已配置问法、上下文问题、重复输入和 10 个要求模型处理的场景。对本次 163 个单元逐一运行，共 6,520 回合。使用相同的新路由代码，对比旧 44 条素材与扩充后的素材，隔离数据扩充本身的收益。

**这是模板覆盖回归集，包含已配置问法，不是未见表达泛化测试，也不是线上真实流量命中率。** 用离线适配器标记哪些回合需要模型，没有为了统计而实际发送 6,520 次模型请求。缓存时延只统计命中路径，不把离线适配器耗时当成模型速度。

| 指标 | 原素材 | 扩充后 |
|---|---:|---:|
| 全部单元检索命中 | 561 / 6,520，8.60% | 2,146 / 6,520，32.91% |
| 需要模型的回合 | 5,622，86.23% | 4,049，62.10% |
| 五年级上册 Unit 10 命中 | 5 / 40，12.50% | 22 / 40，55.00% |
| 同一单元需模型回合 | 32 / 40 | 15 / 40 |
| 远端热缓存路由 P50 | 0.727 ms | 0.694 ms |
| 远端热缓存路由 P95 | 1.005 ms | 1.118 ms |

该场景集需要模型的回合减少约 28%；五上 Unit 10 减少约 53%。规则回复另计 174 回合，教材缺失提示另计，不纳入检索命中。1,630 个指定兜底场景没有出现缓存误命中；这一结果只适用于该测试集。早期单元的词汇较少，部分资源单元的词表覆盖也有限，实际可用素材数量会明显不同。

远端热缓存时延统计不含 HTTP、会话入库、ASR 或 TTS，也不含首次编译词库。扩充后离线编译约 4.29 秒，在服务接收用户请求前完成。

公网真实 HTTP 验收中，9 个命中回合的首段文字为 14.12–23.22 ms，中位数 15.21 ms；3 个真实模型回合首段文字为 589.80–1,006.22 ms。这是少量样本，不能当作长期服务 SLA。

## 验证、发布与复现

- 135 项相关后端测试通过，逐条审计全部可用回复和原句的累计词汇范围，验证来源、未来单元隔离、上下文、否定、替代答案与个人信息边界。
- 公网 13 轮对话通过：连续多轮命中、切换话题、个人事实回忆、跨会话隔离、教材原句轮换和缺失提示。
- 公网真实 WAV → NLS → Bot → Piper PCM 两例通过。ASR 定稿到首段 PCM 就绪约 133／198 ms；这是服务器链路时延，不是物理扬声器出声时延。
- 209 项账户、教材、音频与会话冒烟检查通过，166 个目录单元、1,030 段录音与发布前完整快照一致。
- 只发布两个后端文件和两个数据包；部署文件与已测试候选的哈希一致。备份位于 `/var/backups/real-time-voice/rtv-20261024-bulk-dialogue-r1`，失败可恢复代码、配置和教材数据库；私有对话库不参与替换。

```sh
python3.11 -m pytest tests/test_bulk_chat.py tests/test_chat_library.py tests/test_curriculum_chat.py tests/test_dialogue_policy.py
```

逐单元覆盖清单是本次发布快照。教材词表或单元目录后续变动时应重新编译、测试和导出。详细远端验收记录保存在 `.local/bulk-release-20261024/evidence/`。
