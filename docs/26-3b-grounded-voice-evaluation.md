# 3B 偏好、身份和中文释义：第二轮

日期：2026-11-03。继续使用本机 `qwen2.5:3b`，没有微调、没有使用 9B、没有访问或部署 ECS。

本轮明显改善了偏好记忆和身份回答。中文单词释义改为有依据的查询，中文模型回复增加了播放前的语言检查。最后一批独立题的规则通过率由 46.3% 提升至 93.8%；失败项集中在未保留英文人名、身份说明和多余追问，不能宣称所有对话或中文教学已完全正确。

## 实现

1. 喜欢与最喜欢分开处理。只提取用户自己的明确陈述，忽略模型回复、引用、假设、疑问和其他人的偏好。明确 favourite / like best 才记录为最喜欢；按类别更新或撤回，不把撤回某个类别变成清空所有偏好。处理基于现有会话与已有明确事实，不新增跨会话的个人记忆。
2. 直接询问 Kitty 的年龄或生日时给出一致的真实身份答复。人物年龄、学生年龄和翻译题继续交给模型，避免把“翻译你几岁”回答成“我是 AI”。
3. 词义优先查询带页面证据且未标为不确定的教材词条。缺项可用短释义一致的既有补充词表，来源单独标明，不冒充当前教材原文；另补充 peach、cherry、goose 的可追溯词义。普通复数只回落到已存在的词典词头，不猜造新释义。
4. 中文材料题也获得相关词义提示；light、bank、right 等按上下文选义。明确中文请求采用中文指令，要求翻译问题本身、区分学校科目与语法主语。
5. 明确中文请求在播放前检查语言。若原回复仍以英文为主，最多用同一个 3B 转换一次，带上相关词义依据；仍不能可靠交付则明确失败。普通英文对话继续流式输出，确定性回复无需模型调用。

额外词义来源保存在 `backend/data/chat/voice-glossary-supplement.json`。peach 的水果义核对[香港教育局英汉词汇表](https://www.edb.gov.hk/attachment/tc/curriculum-development/kla/technology-edu/resources/technology-and-living/TL%20glossary%202018_update%202022_final.pdf)，颜色义核对[Cambridge](https://dictionary.cambridge.org/dictionary/english-chinese-simplified/peach?q=peaches)；cherry 核对[Collins](https://www.collinsdictionary.com/dictionary/english-chinese/cherry)，goose 核对[Cambridge 的“鹅”词条](https://dictionary.cambridge.org/te/dictionary/chinese-simplified-english/%E9%B9%85)。这些补充只覆盖选定的基础义，不是完整词典。

## 独立验证

本轮经历多批验证。早期批次暴露了中文指令未触发、词表缺项、材料理解与孤立查词差异、仅关键词通过但整句错误、英文混入中文以及短尾未完成等问题。每次查看后都把那批题转为开发／回归，不重复宣称独立。

最终冻结后的独立集为 40 个全新题，各测两轮，每版本 80 次 Bot 请求，包含数字颜色、物品归属、数量、位置、学校科目等全新短文；此前的真实教材原句验证转为回归批次，并保留教材页路径和哈希。完整历史与此前所有已用数据均不重复，忽略年级后仍无重复。题目覆盖四、八年级，两条语音路径各半。源码与规则在首次运行前冻结，之后没有为了这批题继续改产品或评分规则。

基线恢复上一版提示词和语义处理路径；通用断句与传输修复由两版共享。这是对语义处理的受控对比，不是把完整旧服务二进制重新部署。

新版全部 80 条回复另作逐条阅读复核，见[记录](../evals/voice_chat/v2/review.json)。没有再出现喜欢升级为最喜欢、编造人类年龄或本批词义对应错误。数字“七是红色”“五是绿色”按材料事实回答，没有用常识否定原文；Mia 的物品归属保留原名，数量、位置和学校科目问答均正确。

五条失败如实保留：三条将明确要求保留的 Evie 译为中文人名；另外两条年龄答复没有明确使用 AI 这个词，其中一条还附加了多余追问。两条年龄答复都没有编造年龄。没有把主要事实正确改算成规则通过，也没有事后放宽人名规则。

单一事实中文问题只交付首个完整答句，避免答对后继续补出相反关系；解释、比较、例句及多问题不应用这条简短策略。同时修复中文句号后没有空格时的断句，以及短中英混合答案被误判为英文残句的问题。

对提供材料中明确且无歧义的颜色、物品归属，使用保守的字面事实处理，避免“数字不能有颜色”或人名被重新翻译。否定、多颜色、对象不匹配或缺乏明确关系时不走这条确定性路径；它不是通用阅读理解解析器。

此前批次曾出现关键词正确但后文矛盾，已作为开发案例修复后重新使用全新题验证。历史批次不能混入本批的独立正确率。93.8% 仍只是本批规则通过率，逐条复核也不是独立教师评分；不能据此保证所有多义词、长篇中文理解或真实用户对话都正确。

## 时延及代价

双方使用同一 3B 和相同配置：温度 0.3、4096 上下文、最多 256 个输出 token，预热不计入热启动统计。不存在通过换到 9B 获取质量提升的情况。

| 最终独立集文字交付 | 上一版 | 本轮 |
|---|---:|---:|
| 全部成功回合首段文字 P50 | 123.47 ms | 0.39 ms |
| 全部成功回合首段文字 P95 | 312.44 ms | 578.30 ms |
| 中文材料回合首段文字 P50 | 131.42 ms | 1.43 ms |
| 中文材料回合首段文字 P95 | 317.86 ms | 548.18 ms |

本轮 80 次请求中有 8 次触发了同一 3B 的语言转换。确定性路径较快，但明确中文且走生成的回复会等待语言检查，必要时增加一次转换，所以这部分更慢。没有把确定性回复的亚毫秒时间写成模型推理速度。本批没有交付异常，人名格式失败仍计入通过率。

这些时间不包含 ASR、TTS、浏览器、网络往返或物理扬声器，也不能由此宣称端到端出声 P95。普通英文对话不经过中文缓冲或二次转换。
