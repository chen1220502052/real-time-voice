# 教材章节同步练习

跟读、听力、口语共用“教材版本 → 年级 → 册次与版次 → 章节”的目录。章节身份同时包含版本、年级、版次、单元，不能用单元号跨版本匹配。自由聊天仍是独立入口。

## 当前 Web 版本

入口 `/practice.html`，语音页和文字页均有链接。不调用 TTS、ASR 或 LLM；不会消耗实时聊天会话额度。

| 模块 | 当前行为 |
| --- | --- |
| 跟读 · 单词 | 有本章词表或单词录音即可选择，选中后展开词表。有官方词汇录音时可播放跟读；没有独立录音时隐藏播放工具和来源说明，可看词表并录下自己的朗读。词卡先选择一个词，显示英文、释义及其独立示范音；同一张卡片内依次提供“听示范 → 我来读 → 听我的录音”，可前后切词。示范缺失或加载失败不能冒充可用的跟读。词表区分教材词表与原创主题补充。 |
| 跟读 · 课文／对话 | 已配好点读的页面以教材插图作场景背景，语句作为独立对话气泡，每句后有原音播放和“跟读”按钮。原音播放对应片段并在句尾停止；跟读直接录音，结束后可交替听同一句原音、自己的录音，或重新跟读。首次进入优先选择可点读的材料。未配逐句数据的页面保留原图、整段录音及“跟读这一页”入口；没有原图时隐藏图片区，不显示资料尚未准备或引导对照手边教材的提示。 |
| 听力 | 同章教材活动录音，先听再记要点，翻书核对；不显示主题词提示，不编造原文或答案。 |
| 口语 | 同章原创主题问题、表达任务、可展开的原创示范，学生自行作答和录音。当前不是 AI 连续追问。 |
| 录音对照 | 浏览器临时录音、回放，最长 120 秒，不上传；切章、切模式、切材料、切换跟读目标、后台及离开页面清除。播放原音不会清除跟读录音；回听按钮仅在录制完成后显示。 |

当前索引包含人教版 3—9 年级 84 单元、科普版 3—9 年级 118 课/单元。三年级包含人教版 12 单元、科普版 24 课，支持本地图片、原音和原创口语任务；科普版三年级词表已按原图和单元边界结构化，支持作文；人教版作文仍需导入核验词表。数据来自仓库内已整理的索引，不代表学校所有册次或版本均已覆盖。科普版已收集的本地原图与音频按索引提供；原创示范明确标注，词表核验状态与教材版次单独记录。官方在线资源的实时可用性需以原站为准。

## 录音与文本

录音下拉框优先使用已核对的教材小节与活动标题，例如 `Let’s Learn A · 1. Listen, look and say`、`Let’s Read · You Eat Like a Horse!`，教材图片标题同步更新。`backend/data/practice/recording-titles.json` 按教材原图 SHA-256 绑定标题，仅应用于同章明确配对的录音；当前已核对科普版四上 Unit 1 的全部 10 段。其余尚未核对的材料保留原有标题或分段编号。

课文使用已收集的教材原音。单词优先复用已收集的独立发音录音；缺少单词录音时使用预先生成并标注“合成示范发音”的 Piper 英语音频。合成音不标为教材原音，不在请求时调用 TTS。有本地 MP3 时走可定位的音频端点，缺文件时使用索引中官方 MP3 地址；没有直链则展示官方资源网页。页面不自动抓取第三方素材。

当前逐句点读样例为科普版四上 Unit 1 的早餐对话，四句文本按教材图核对，音频区间按原录音中的停顿边界加前后余量设置。`backend/data/practice/dialogue-scenes.json` 定义场景裁取范围、气泡位置、文本与时间段，并绑定图片和音频 SHA-256，资源变更后不沿用旧时间点。背景使用教材插图的派生版本（通过 imagegen 去掉印刷气泡，原文件不变），句子与按钮为可访问的 HTML 元素。手机布局把句子排在场景上方，保持文字可读并避开人物。点其他句子、切材料／章节／模式、进入后台或开始录音时，停止当前点读。录音和原音回放互斥，麦克风授权等待中切换内容会释放迟到的音轨。每句使用原录音，不使用合成语音。

其他文章逐篇补齐课文文本、场景和录音起止时间后才能提供相同点读方式，不能拿 ASR 自动转写或原创示范冒充教材原文。发布前继续遵守已有资料包中记录的素材使用范围。

自动评测与“已完成”进度尚未接入。浏览器录音不构成发音评分；听力笔记也不构成已批改答题结果。后续学习记录应以“学生 + 章节 + 模式 + 材料”为键，听力另记重听、看原文、提示等辅助动作。

## 服务接口与运行

- `GET /api/practice/catalog`：章节目录、录音数量及缺少索引的教材版本。
- `GET /api/practice/chapters/{chapter_id}`：章节录音、原创主题词、口语任务及来源。
- `GET /api/practice/audio/{audio_id}`：只返回索引内且目录内的 MP3，支持 HTTP Range；不开放整个资源目录。
- `GET /api/practice/textbook-pages/{page_id}`：只返回索引内教材原图。章节详情的 `textbookPages` 提供图片与本章录音的配对；听力模式隐藏原图。

默认资源根目录为仓库 `英语/`。部署时可配置 `ENGLISH_RESOURCE_ROOT` 指向资料目录，保留 `人教版/新版单元听说训练.json`、`科普版/单元原创补充训练.json` 及索引中的音频相对路径。只发布后端和 Web 代码不会自动携带这些资源。更换索引后重启服务以更新进程内目录缓存。

没有资料目录时，目录 API 返回空章节和缺失版本，页面提示配置资源，聊天服务照常运行。

验证：`python3.11 -m pytest tests/test_chapter_practice.py`、`node --check web/practice.js`。

## 面向 9–15 岁的短目标跟读（2026-10-24）

跟读以一个词、已核对的一个句子或一小段为目标。示范、录音、回听、上一项和下一项留在同一张卡片内；不自动申请麦克风。单词录音最长 10 秒，课文目标录音最长 30 秒。手机端课程选择折叠，按钮纵向排列。没有示范音的词仍可查看，但不能直接开始跟读录音。

`word-audio.json` 将规范化词条绑定到本地文件 SHA-256、时长和来源类型；运行时校验资源路径和内容后才下发播放地址。独立单词录音可以来自已收集的其他课次，统一标“单词示范录音”，不冒充当前课次的原音。

`audio-excerpts.json` 将课文音频 SHA-256 绑定到时长及短区间。自动短段仅沿至少 240 毫秒的安静停顿切分，每个目标不超过 18 秒；连续音乐或无法取得安全短段的材料不强行按固定秒数截断。没有已核对文本的片段显示“小段”和对应课本图，不展示 ASR 猜测原文，也不声称逐句对齐。`excerpt-overrides.json` 保留针对原音的人工边界调整，构建脚本重跑时会应用。

整课录音折叠在“完整听一遍”中，不作为默认跟读目标。课文练习优先选择对话与故事，隐藏已识别的听力题和连续歌曲；科普四上 Unit 2 的小节标题已按教材图改为内容名称。其余没有核对语义标题的材料以“看图听读 · 第 N 部分”配合实际课本图定位，不能根据序号编造故事名称。
