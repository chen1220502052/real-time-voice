# 首页与原创样板单元

更新：2026-10-23。本文记录已实现范围；整体规划见 [产品设计](17-grade4-9-english-learning-product-design.md)。

## 入口与运行

沿用现有 Python/aiohttp 服务，无前端构建依赖。

- `/`：学习首页，四个导航为今日学习、我的课程、专项练习、学习记录。
- `/#course`：显示当前所选课程；分级拓展目前提供六年级原创样板“我的周末计划”。
- `/#lesson/words`、`sentences`、`listening`、`reading`、`speaking`、`review`：六个环节。
- `/voice.html`：原实时语音聊天；文字模式下跳转 `/text.html`。
- `/index.html`：保留原语音演示台兼容地址。
- `/practice.html`：现有教材章节录音练习，仍单独展示资源覆盖范围。

语音页默认只展示通话、课程和实时字幕，状态与错误提示面向学习者。开发排查可在语音页地址加 `?debug=1`（已有参数时用 `&debug=1`），显示录音打标、延迟测量、模型指标和事件时间线；普通模式不自动录制诊断音频。本机 `?diagnostics=1` 音频验收入口也会显示调试工具。

仅验证课程界面时，可不加载音频模型：

```bash
VOICE_ENABLED=0 PORT=8872 BOT_STATE_DB=:memory: python3.11 -m backend.app
```

访问 `http://127.0.0.1:8872/`。现有实时聊天继续使用原启动脚本和模型配置；课程本身不调用云端 API。

## 年级与课程切换

右上角“切换课程”打开课程选择弹窗。先选 4–9 年级与教材同步／分级拓展，再选教材版本、册次与版次、单元。教材选项来自 `/api/practice/catalog`，按年级与版本逐级过滤。

教材同步的首页、课程页、专项页显示当前单元及本册目录，提供跟读、听力、主题口语入口。进入练习时，通过 `/practice.html?chapter=<章节标识>&mode=<模式>` 定位到准确单元；教材练习页重新选课后，首页也会沿用新选择。无效章节链接显示不可用提示，不自动打开别的单元。

分级拓展目前只有六年级完整样板；选择其他年级会显示待补充，并提供明确切换到六年级样板的按钮，不把同一份六年级内容改标为其他年级。教材目录加载失败可重试，缺少目录或录音时说明可用范围。

课程偏好使用 `course` 云端文档，浏览器待同步日志的基础键为 `kitty-course-selection:v1`，与样板进度分开；取消弹窗不保存，切换年级与教材不清除学习进度。直接打开六环节样板链接时，课程切回六年级分级拓展。学习记录页明确标注六年级样板记录。

## 样板内容

| 环节 | 已实现 |
| --- | --- |
| 单词 | 6 个词或词块、音标、词义、例句及示范录音；收起词卡后做 6 道回忆题 |
| 句子 | 3 个句型、中文说明、示范录音、2 道选择题及 1 道受限造句题 |
| 听力 | 原创短对话、完整播放后答题、3 道理解题；记录重听、慢速、关键词及原文辅助 |
| 阅读 | 原创三段短文、全文录音、3 道主旨/细节/原因题、反馈及原文段落定位 |
| 口语 | 提示与示范、文字草稿、最长 60 秒本机录音回放、三项目标自查；现有聊天入口 |
| 复习 | 优先选择到期知识点，词义题改为反向识别；无到期项时混合巩固词句及听读 |

答错可根据反馈重试，答对后继续。每环节最后确认继续时记录完成。口语需要录音完整回放或文字草稿，并完成自查；只记录自查完成，不自动判断语法、内容或发音质量。

## 记录与边界

启用账户时，课程与进度通过 `/api/account/learning` 保存到后端 SQLite，按用户隔离，支持重新登录和跨设备恢复。写入采用版本号检查，重复提交不重复递增，多设备冲突不会静默覆盖。浏览器 `localStorage` 仅作按用户隔离的待同步日志，进度基础键为 `kitty-learning:weekend-v1`；未启用账户时使用本机档案。学习记录页有清除入口，须二次确认。

保存题目位置、草稿、首次答题与辅助状态、重试次数、知识点状态及复习时间。同一天重复答对不增加长期记忆证据；至少间隔一天再次独立答对，才标记间隔后保持，并把复习间隔延长到三天。错误或辅助作答保持待复习。复习规则是首版产品参数。

词卡展开时提交词义题记为辅助作答。听力暂停后继续不算重新听一遍；拖到录音结尾不能代替完整播放。重新练习听力时重置本轮辅助状态。录音在切页、页面隐藏或离开时释放麦克风并清除，不上传、不持久化；现有聊天维持原有服务链路。

内容、播放素材、题目和进度逻辑分别位于 `web/learning-data.js`、`web/audio/weekend/`、`web/learning.js`、`web/learning-store.js`。示范录音均为原创文本的本地合成语音，界面明确标注；不是教材原声。

macOS 上可用 `python3.11 scripts/generate_sample_audio.py` 重建录音；需要本机 `node`、`say`、`afconvert` 及 Samantha、Daniel 系统音色；听力对话使用两种音色区分人物。其他系统直接使用已附带的 M4A 文件。

## 共用视觉主题

2026-11-05 界面检查：普通页面不展示服务健康、连接诊断、词汇统计或内部校验说明；保留加载、失败和未保存提示。文字聊天提供简短的空白页引导，失效课程链接结束加载并明确引导重新选课。手机词卡使用单列，六个练习标签全部可见；选课区只在首次加载时折叠，连续修改教材、年级和册次时保持展开。手机写作优先展示自己的作文，嵌入写作按内容自动调整宽高。主题口语默认围绕当前问题录音，不使用无关的课文录音作为示范。

所有前端入口（首页、登录注册、教材练习、文字聊天、语音聊天）均在原布局样式后加载 `web/theme.css`，课程页、六个训练环节及弹窗共用这份主题。以课程选择参考图为基准：暖白背景 `#fffef9`、深绿标题、浅绿表单与提示卡、绿色主按钮、统一圆角及宽松间距。正文和表单标签的绿色略加深以保证可读性，错误与警告仍保留明确的语义色。

`web/account.css` 使用相同主题变量及对应回退色，账号控件放在页尾，避免遮挡手机底部导航。语音页保留猫猫动画、设置和诊断功能，使用浅绿背景代替原深色渐变。手机展开设置后，面板限制在页面左右边界内。

登录页也需要共用主题，因此 `/theme.css` 为公开静态样式资源；账户上下文、学习数据与教材接口的登录要求保持原有规则。后续新增页面应加载共用主题，避免再次形成独立配色。

本次样式验收：13 个已登录页面／训练视图在 1280 与 390 像素宽度下均采用浅色主题且无横向溢出；另检查登录注册、课程选择、实际文字回复气泡、语音设置与展开诊断。浏览器未记录错误。相关账户、入口、文字聊天及教材接口共 14 项回归通过。
