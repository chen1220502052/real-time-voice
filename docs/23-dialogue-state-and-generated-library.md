# 对话策略、会话状态与生成回答入库

日期：2026-10-23。版本：`rtv-20261023-dialogue-state-r3`。

## 对话流程

用户输入先经过确定性的状态投影与策略选择，再选择教材、预置问答、已生成的通用回答，仍无合适内容时使用现有 Deep Agents + DeepSeek 一次生成。词汇范围仍约束所有检索与固定策略句；实时模型兜底没有硬词汇限制。

状态包括当前／前一个话题、连续重复次数、最后一个已交付的追问、最近六个已交付回复、练习模式与最多八条明确表达的个人事实。语义历史仍由 BotService 根据显示／播放回执维护，未播放的生成草稿不作为孩子听过的回复。用户明确说出的喜好、宠物名字等会在本会话保留，能在历史窗口截断后继续提供给模型；状态不会跨会话读取。

- 第二次规范化后相同的输入：优先更简单的问题或两选一，避开刚用过的回复。
- 第三次及以后：从其他简单话题选问题；候选耗尽或词汇不满足时由模型处理。
- Why、What about、Yes／No 等依赖上下文的短句：保留历史，让模型理解，避免无上下文的固定答案。
- 明确换话题或识别到新主题：跟随最新话题。
- 明确要求练习／跟读：配合练习，不按重复次数强制换题；明确停止、切换话题时退出。

这是轻量规则层，含糊意图和未覆盖话题仍交给模型；不是对所有自然语言的完美意图识别。重复计数来自 BotService 已接受的用户轮次，不来自 ASR partial；相同请求 ID 的重放仍由现有协议去重。

## 持久化与共享边界

新增独立 SQLite 数据库 `CHAT_DIALOGUE_DB`，默认位于 `ACCOUNT_DB` 同目录下的 `chat-dialogue.sqlite3`。它不参与教材快照重建。生产路径是 `/var/lib/real-time-voice/chat-dialogue.sqlite3`，文件权限 0600，所有者为服务账号。

`dialogue_turns` 保存完整回复、输入、会话／单元 ID、回复来源、状态快照和分类。模型成功完成后、发出 done 前自动写入；检索和策略回复也记录。中途取消的生成不作为完成回答入库，既有 BotService 日志仍保存流事件及实际交付事实。SQLite 操作在线程中执行，避免阻塞语音事件循环；按会话 ID 与 request ID 联合幂等写入；升级时保留旧表记录。

分类为：

- `general`：明确、自足的常见知识问法，且上下文无个人内容、回答通过保守自动检查。
- `personal`：出现个人称谓、姓名／联系方式等线索，或会话带有明确个人事实；仅供本会话使用。
- `contextual`：依赖上下文或不能可靠判断的内容；同样保留在私有记录中，不共享。

分类使用代码规则，不由模型自行声明。当前共享入口只开放 16 个明确的常见知识问法，对个人称谓、数字／链接、异常大写专名和中文内容采取保守排除；其他问答仍然直接保存，但不自动共享。此规则不是通用隐私识别器，后续扩展公共问法时应继续补充隔离测试。

只有模型完整生成、分类为 general、普通回答动作且并非重复输入的结果，自动写入 `general_replies`。共享查询只按当前单元和完整问句匹配，且再次检查个人信息边界、最近回复与已学词汇。生成时出现新词仍允许交付和保存；复用时词汇超出范围则不命中。自动入库不等于已经人工核实事实正确。

带单元的机器人不再允许对未定稿 ASR 输入做有写入副作用的推测生成，避免把推测草稿写进真实会话。无单元的原有语音流程不受此项改动影响。

## 验证与发布

自动测试覆盖：重复输入换问法／换题、显式练习和退出、多轮追问、话题切换、个人事实跨历史窗口恢复、跨会话和跨单元隔离、公共回答复用与词汇检查、重复请求幂等写入、取消时不提升草稿。

发布只更新 `backend/curriculum_chat.py`、`backend/dialogue_policy.py`、`backend/dialogue_store.py`，保留远端已有的写作与前端发布。检查目标文件和依赖没有并发变更，在无活跃会话时备份代码与配置，再切换服务；公网验收失败自动恢复之前代码和配置。隔离测试库不复制到生产。

最终已发布到 `https://aimaoren.com`，版本 `rtv-20261023-dialogue-state-r3`，服务健康且验收后资源占用为 0。三个部署文件的 SHA-256 与本地及已测试候选一致。

- 130 项后端回归通过，包括旧数据库迁移、不同会话使用相同请求 ID，以及重放不重复入库。
- 隔离环境 17 轮真实模型对话通过；完整生成与策略回复均已保存，通用回答进入独立共享表，Luna 等个人内容没有进入共享表。
- 公网 15 轮对话通过，覆盖连续四次相同输入、明确切换到食物、宠物名字回忆、其他会话隔离、Why／What about 追问和练习模式；重复请求返回原结果，不新增轮次。
