# 单元词句库与三层对话

日期：2026-10-23。版本：`rtv-20261023-hybrid-chat-r2`。

## 当前规则

1. 先找有原文依据、且回复词汇属于当前累计范围的教材答案。
2. 教材没有可靠匹配时，查提前编写、审核并入库的常见问答；同样只选当前累计词汇能够覆盖的回复。
3. 仍未命中时，由 Deep Agents + 现有 DeepSeek 生成一次常见、简短、适龄的回答。**这层不再执行词汇白名单、3% 配额或超纲重写。**按完整句子交付，可用于文字或 TTS。

这取代此前每条回复都必须满足累计词汇限制的策略。检索层的句子受词汇范围约束，生成兜底可能出现新词。

高频场景可以枚举；开放式话题、个人事实、含糊指代和自然语言的所有变体不能穷举。未命中时走生成，比用相似关键词强塞一个现成答案更合适。

## 词库与答案库

使用 SQLite，默认与 ACCOUNT_DB 同目录，可用 CHAT_LIBRARY_DB 指定。数据库保存：

- `chapters`：按单元 ID 查询的词汇快照和来源、覆盖情况。
- `unit_words`：每个单元自身的词汇。
- `cumulative_words`：各单元截止位置对应的累计词汇，保留出版社和教材系列边界。
- `answers`、`questions`：已审核答案、问法及必要的上一轮上下文、教材来源。
- `eligible_answers`：离线计算每个单元可以使用哪些答案，实时命中无需重新扫描词表。

首批包含 163 个可排序单元快照、4,365 条“单元—词”记录，以及 2 条教材回复和 42 条原创常见问答。它不是 4,365 个去重单词，也不表示媒体目录新增了 163 个可播放单元。

教材词汇导入现有结构化教材资料；附带的数据包支持未部署原图资料的服务器构建同样的词汇数据库。每条教材回复要求问题、答案在声明的同一份原文证据中确实存在，不把原创主题练习冒充教材原文。当前可直接复用的已核对教材问答很少，仍需逐步补齐。

构建命令：`python3.11 -m scripts.build_chat_library`。导入使用临时文件和原子替换，失败保留旧库。源文件内容或版本变化后重建；内存快照随数据库代次失效。冷构建在工作线程执行，不阻塞音频事件循环，生产发布前先完成构建。

## 匹配与上下文

当前采用大小写、常见缩写、标点规范化后的整句匹配，以及显式录入的同义问法。否定词保留；没有可靠命中时不作宽泛关键词猜测。Yes/No 等短回复必须匹配上一轮助手问题。已出现过的缓存追问不再反复发送，交给模型结合上下文接话。

模型处理个人事实、回忆、陌生问题和新话题，保留既有会话历史、播放确认和未播放草稿的续接规则。模型只有一次生成，不携带完整词表，也不使用规划、文件或子代理工具。通话断开会关闭生成流。

本版原先只保存私有会话记录。后续版本新增对话策略和生成回答自动分类入库：通用回答经过保守检查后可共享，个人及上下文相关内容保持私有，详见 [对话状态与生成库](23-dialogue-state-and-generated-library.md)。以下时延和原始版本验收记录保留供比较。

回复来源记录在服务端 `bot.latency` 的 `chatReplySource`，值为 `textbook`、`prepared`、`generated`，并记录查询时间和命中答案 ID；页面不展示这些内部实现细节。

## 语音接入

文字页切换语音时携带 chapter 参数。浏览器先读取并验证单元，再允许拨通；单元年级固定，不会在通话中随意改变。WebSocket create_session 可传 chapterId，后端将它贯穿 Session 和 BotRequest，使用同一套三层策略。

带有效单元的语音支持四、五年级，使用较慢语速。不带单元的旧语音入口仍按原六至九年级方式工作。语音媒体、打断、播放回执仍由既有链路管理。

CHAT_WARMUP_ENABLED=1 在接收连接前加载数据库及兜底 SDK，不调用模型 API，避免首次兜底额外支付 SDK 导入时间。

## 测试与测量口径

本地相关后端 106 项通过，前端连接、播放与时序 5 组及语音选课 2 项通过。远端同组后端回归 106 项通过。

远端真实模型与检索试验覆盖教材优先、预置问答、否定句、个人事实记忆及陌生话题；8 条均完成。预热后四次兜底首句约 0.71–0.98 秒，检索命中首条文本约 0.9–3.8 毫秒。200 次独立 SQLite 查询中位约 0.38 毫秒，最慢约 20 毫秒。这是小样本结果，不是 SLA 或用户网络延迟。

真实 WAV → NLS ASR → 三层 Bot → Piper TTS 试验中，两个检索命中样本从 ASR 定稿到首段 PCM 分别约 108 和 156 毫秒；此前生成并校验的试验约 3.3–5.2 秒。录音、回答、年级设置和生成路径有差异，只能说明命中检索后省去了模型等待，不能作为严格的因果 A/B 或 P95。
